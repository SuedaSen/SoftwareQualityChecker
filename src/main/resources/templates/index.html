What is ML?

ML = Machine Learning: the computer learns from data.

“Tutarsızlık adayları” bulunurken iki gereksinim ne kadar benzer diye bakıyoruz. Benzerlik hesabı iki şekilde yapılabiliyor:

  • ML ile (kelime vektörü): Kelimeler sayı listelerine (vektörlere) dönüştürülmüş; bu sayılar daha önce büyük metin verilerinden öğrenilmiş. Cümle = kelimelerin ortalaması; iki cümle ne kadar yakınsa benzerlik o kadar yüksek. Yani benzerlik burada öğrenilmiş temsillerle hesaplanıyor → bu ML kullanımıdır.
  • TF-IDF (ML değil): Sadece kelime sıklığına dayalı basit bir formül. Öğrenen bir model yok; yedek olarak kullanılır.

How can you tell?

Why is ML needed in this project?

Requirements can be written in many ways; rule-based similarity often misses same or conflicting pairs. ML word embeddings capture meaning.

Without ML we rely only on word overlap (TF-IDF). With ML, similarity is based on learned representations, improving conflict detection.

About the project

Aim: to flag ambiguous and inconsistent requirement pairs.

What was done?

  • Ambiguity (rule-based): shall/should/may, numbers, weak wording.
  • Inconsistency (ML + rules): similarity via ML or TF-IDF; negation/number rules.
  • Web UI: paste or upload CSV, TXT, DOC, DOCX, PDF; view and download CSV.
